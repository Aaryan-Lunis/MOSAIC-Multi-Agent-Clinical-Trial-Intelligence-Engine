# Data Sources and Knowledge

This category contains the research papers that define the biomedical data sources, knowledge repositories, and structured information used by the **MOSAIC – Multi-Agent Clinical Trial Intelligence Engine**.

These papers explain how clinical trial information, biomedical literature, and knowledge graphs can be accessed, integrated, and utilized for intelligent clinical reasoning.

## Research Focus

- ClinicalTrials.gov
- PubMed
- PubMed eUtils
- AACT Database
- Biomedical Knowledge Graphs
- Biomedical Knowledge Retrieval

## Papers

| Paper | Primary Contribution |
|--------|----------------------|
| GeneGPT | Biomedical question answering using NCBI web APIs |
| AACT Database | Structured ClinicalTrials.gov relational database |
| PubMed Knowledge Graph 2.0 | Large-scale biomedical knowledge graph from PubMed |
| AACT-based Biomedical Knowledge Graph | Knowledge graph construction from clinical trial data |

## Why This Category Matters

These papers establish the data foundation of MOSAIC. They describe where biomedical knowledge originates, how it is structured, and how it can be queried efficiently. The concepts from this category directly influence the Data Ingestion Layer, Knowledge Base, Retrieval Pipeline, and API integration components of the system.
